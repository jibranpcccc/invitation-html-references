# Reference contract

Brand: **Norvella House**. Read `brand/BRAND.md` for verified source assets, interface styling and desktop/laptop support wording. Keep branding out of invitation exports.

Scope changes to the assigned products. The user's instructions and approved master protocol take precedence.

- Treat these HTML editors as reusable engineering references; each new product still requires visual calibration and a validated clean background.
- Never claim native 300 ppi illustration detail from the resampled 1060 × 1484 source artwork.
- Preserve all fixed art, ages, ornaments and dividers. Remove every original editable glyph, outline and shadow. Do not conceal old text with flat patches or baked-in lettering textures.
- Render every editable field through the same renderer at startup, during edits and on export.
- Keep bold, italic, underline, colors, separate edge/effect colors, fitting, selection, placement, history and saving functional. An inert control fails acceptance.
- Invalid fields must leave a clean local background and the other fields/art visible, with useful field errors and print exports blocked.
- Never silently truncate content, force case, clip painted bounds or shrink below the field minimum. Point-size limits and line wrapping must remain explicit.
- Validate settings atomically. Save/load and personalized HTML must preserve all supported properties.
- PNG: 1500 × 2100 at 300 ppi metadata. PDF: one 360 × 504-point page. Treat artwork detail and export dimensions as separate facts.
- Run appropriate verification after changes, inspect actual pixels and downloaded files, then update the HTML hashes and preview. Report limitations honestly.
- Do not invent a shop name, logo, license, brand approval, bleed requirement or browser compatibility claim.
